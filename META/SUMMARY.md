# META — Summary

## Method

**Fuse explicit parents → partition by intention → lock axioms → name by job → layer strictly → split decide/carry out → require allow/bound/record/reverse → protect Baseline → reject drift → test by canonical speech.**

## Rules (non-negotiable)

1. No silent third parent on L0–L2  
2. Every kernel concept maps to an intention (or correlation)  
3. Features cannot relax axioms without amendment  
4. No primary rename of frozen concepts  
5. Encodings are not conceptual core  
6. No acceptance without canonical speech
