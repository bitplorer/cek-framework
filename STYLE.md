# Style

Documentation conventions for this charter.

## Prefer

- Frozen vocabulary only in normative text  
- Short tables and numbered paths over wide ASCII art  
- **Mobile-safe** landing text: no fixed-width boxes wider than ~40 characters on README  
- Pointers from hubs to detail docs (power stays in CORE)  
- Canonical speech test for amendments  

## Avoid

- Synonym names for Cap, Ops, Host, Peer, lineage, Baseline  
- Implementation languages, crate paths, or CI as if they were law  
- Marketing renames of kernel terms  
- Wide box-drawing diagrams on README (use tables; put wide art in diagrams/ or CONCEPTS with a plain alternative)  

## Hub docs

README and CONCEPTS must remain readable if Mermaid and wide ASCII are stripped.
