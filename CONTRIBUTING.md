# Contributing to the charter

This repo is a **conceptual freeze**, not an application codebase.

## Allowed without amendment

- Editorial clarity that does not change meaning
- New published conformance *vectors* that test existing law
- New drafts under `PROPOSALS/`

## Requires charter amendment

See [CHARTER.md](CHARTER.md). Process:

1. Canonical speech ([META/10](META/10-canonical-speech-test.md))
2. Layer + change class ([CORE/12](CORE/12-change-law.md))
3. Axiom / naming / Baseline check
4. Invariants ([CORE/18](CORE/18-invariants.md)) + conformance ([CORE/19](CORE/19-conformance.md))
5. Log in CHARTER

## Style

Follow [STYLE.md](STYLE.md). Prefer pointers in hubs; keep power in CORE detail docs.
