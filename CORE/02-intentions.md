# CORE 02 — Intentions

## Closed intention set

| Intention | Concepts |
|-----------|----------|
| Ask | Intent, submit |
| Allow | Cap, mint |
| Carry out | Ops, apply, Result |
| Bound | Activity, Context, inject, limit, isolate, part |
| Remember / undo | lineage, reverse |
| Correlate only | trace |

## Orthogonality

**trace** does not participate in ask/allow/carry out/bound/undo.  
It only relates Intents that already satisfy those intentions.

## Completeness rule

Every kernel noun and verb appears in exactly one row above (Host/Peer/Baseline/profile are role and permanence concepts supporting the same rows: Host/Peer support allow and carry out; Baseline/profile support permanence and negotiate-carry-out).

### Supporting concepts (not a seventh intention)

| Concept | Supports |
|---------|----------|
| Host | Allow + decide path for carry out |
| Peer | Carry out |
| Baseline | Permanence of ask/allow/carry out law |
| profile | Negotiation of carry-out ability |
